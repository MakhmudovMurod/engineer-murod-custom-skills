# Engineer Murod Custom Skills

Reusable custom skills created for Engineer Murod's AI and automation workflows.

## Available skills

### `uzbek-telegram-native-ad-copy`

Writes natural Uzbek Telegram advertising copy, native integrations, promotional posts, hooks, and calls to action. Its methodology is based on analysis of publicly accessible posts from established Uzbek creator channels.

It includes:

- Natural Uzbek copywriting rules
- Native advertising structures
- The TANISH copy framework
- Hook and CTA libraries
- Direct and creator-led advertising formats
- Claim, disclosure, and compliance checks
- A source-backed Telegram channel analysis

## Installation

Copy the desired skill directory into your Hermes Agent skills directory:

```bash
cp -R skills/uzbek-telegram-native-ad-copy ~/.hermes/skills/
```

Then start a new Hermes session or refresh skill discovery. The skill will activate for requests involving Uzbek advertisements, Telegram promotional copy, native integrations, sales posts, and CTAs.
